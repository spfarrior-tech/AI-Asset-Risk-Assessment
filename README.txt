#AI Asset Risk Assessment Project

##Overview
This project uses Python and pandas to automate asset risk analysis and reporting.

## Features
- Reads Excel asset data
- Calculate asset risk score
- Rank highest-risk assets
- Exports risk assessment report to Excel
- Generate a professional PDF summary report

## Technologies Used
- Python
- pandas
- reportlab
- openpyxl

## Purpose
This project demonstrates workflow automation, operational intelligence, and reporting automation capabilities.
